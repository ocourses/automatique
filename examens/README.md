# Examens d'automatique

Ce répertoire contient les sujets d'examen disponibles et certains corrigés.
Les examens d'Automatique de première année sont classés par année
universitaire. Comme seule la session 1 est publiée ici, chaque année contient
un sujet et, lorsqu'il est disponible, un corrigé directement à sa racine :

```text
examens/AAAA-AAAA/sujet.pdf
examens/AAAA-AAAA/correction.pdf
```
