# Examens d'automatique

Les examens d'Automatique de 1re année sont classés par année universitaire. Comme seule la session 1 est publiée dans ce dépôt, il n'y a pas de sous-répertoire de session :

```text
examens/AAAA-AAAA/sujet.pdf
examens/AAAA-AAAA/correction.pdf
```

Les sujets et corrections disponibles sont publiés pour chaque année. Le dépôt enseignant contient désormais les corrections 2024–2025.
